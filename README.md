# ひらく — HTMLの本棚

スマホで HTML ファイルをひらくためのアプリです。ホーム画面に追加すると、アプリのように使えます。

**ひらく：** https://yooooh2418-glitch.github.io/hiraku/

## 使い方
1. 上のリンクを Safari（Android は Chrome）でひらく
2. 画面の案内にそって「ホーム画面に追加」する
3. ホーム画面の「ひらく」から「HTMLファイルをえらぶ」を押して、ファイルを選ぶ

LINE で届いたファイルは、先に「“ファイル”に保存」（Android は保存）してから選びます。

## できること
- 1ファイルの HTML（資料・プレゼン）をひらく
- 中で保存するアプリ（チェックリスト・学習アプリなど）を使う。保存した中身は閉じても残る
- 画像のフォルダがあるページは、フォルダごと ZIP にまとめて入れる
- パソコン向けのページを画面の幅に合わせる／文字の大きさ4段階／目次／ページ内検索／続きから
- LINE・AirDrop などで人に送る
- 4けたの暗証番号でロック（のぞき見防止。ファイルの暗号化ではありません）
- 電波がなくても、本棚に入れた物はひらける

## 入れたファイルについて
- 入れたファイルは、そのスマホの中（ブラウザの保存領域）だけに保存します。どこのサーバーにも送りません。
- 読み込んだ HTML は、ほかの本やほかのアプリのデータに触れない囲い（sandbox）の中で動かします。
- ひらくを消したり、スマホの空きが足りなくなったりすると、本棚も消えることがあります。元のファイルは取っておいてください。

## 対応していないもの
- 中で indexedDB を使うアプリ（保存ができません）
- JS をモジュール（`type="module"`）で別ファイルから読み込むページ
- パスワード付きの ZIP

## 作り
サーバーの処理はありません（GitHub Pages の静的ファイルだけ）。外部のライブラリは QR コード生成の `qr.js`（qrcode-generator / Kazuhiko Arase・MIT License）のみで、このリポジトリに同梱しています。
